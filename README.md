## 🌟 О проекте

**FreeChat** — это автономный, экстремально лёгкий и быстрый мобильный клиент для работы с более чем **400+ языковыми и мультимодальными нейросетями** через шлюз [OpenRouter.ai](https://openrouter.ai).

Приложение написано на **чистом Android SDK** без единой тяжелой внешней библиотеки (без Jetpack Compose, androidx, Glide или OkHttp). Приложение написано на **чистом Android SDK** без единой тяжелой внешней библиотеки (без Jetpack Compose, androidx, Glide или OkHttp). При объёме APK **всего ~165 Килобайт** вы получаете возможности полноценных клиентов уровня ChatGPT, Telegram и Google Gemini:
- **Интерфейс в стиле Google Gemini:** верхнее меню `☰`, выпадающая плашка модели, стартовые карточки-подсказки и плавающее поле ввода.
- **Поддержка 10 языков:** автоопределение языка смартфона (Русский, English, Español, Deutsch, Français, 中文, Türkçe, Қазақша, O'zbekcha, العربية).
- **Живой стриминг ответов** (Realtime SSE)
- **Полноэкранный поиск по каталогу 400+ моделей OpenRouter**
- **Анализ изображений и фото с камеры с предпросмотром**
- **Копирование любого промпта, ответа или блока кода в 1 клик**
- **Фирменные цветные монограммные бейджи провайдеров** (Google, OpenAI, Anthropic, DeepSeek, Meta, NVIDIA и др.)

## 📸 Скриншоты и возможности интерфейса

### 1. 🤖 Каталог 400+ моделей с поиском и фильтрами
- **Интерактивная плашка модели в шапке (в стиле Gemini):** нажмите на название модели со значком `✦` вверху экрана, чтобы мгновенно открыть каталог.
- **Мгновенный поиск:** фильтрация по названию, ID и провайдеру (`gemini`, `deepseek`, `llama`, `claude`, `qwen` и др.).
- **Быстрые фильтры:**
  - `[ Все модели ]` (полный каталог OpenRouter)
  - `[ 🎁 Бесплатные ]` (только модели с бесплатным доступом `:free`)
  - `[ 📷 С фото (Vision) ]` (модели с поддержкой зрения)
- **Цветные аватар-бейджи провайдеров:** круглые монограммные чипы брендовых цветов: Google 🔵 (`G`), Meta 🔷 (`M`), DeepSeek 🟣 (`DS`), OpenAI 🟢 (`OA`), Anthropic 🟤 (`AN`), Mistral 🟠 (`MS`), NVIDIA 🟩 (`NV`), Qwen 🟣 (`QW`). Никаких битых глифов или квадратов шрифта!
- **Метки характеристик:** метки `[FREE]`, `[📷 VISION]`, контекстное окно (`1M ctx`, `262K ctx`, `128K ctx`).
- **Своё ID модели:** возможность вручную ввести любой идентификатор модели.

### 2. 📷 Зрение и фото (Vision)
- **Интерактивные миниатюры:** перед отправкой фото отображается в виде карточки со скруглёнными углами и кнопкой удаления `✕`.
- **Фотографии в пузырях чата:** изображения выводятся прямо в переписке.
- **Полноэкранный просмотрщик:** нажмите на любое изображение в чате, чтобы открыть его во весь экран с высоким разрешением.
- **Автоматическая умная компрессия:** 15–20 МБ фото с камеры смартфона пережимаются до 1600 px в JPEG 85% (~400 КБ), исключая ошибки переполнения памяти (`OOM`) и сбои API `HTTP 413`.

### 3. 📋 Копирование промптов и кода в 1 клик
- **Копирование любого блока кода:** в правом верхнем углу каждой карточки кода есть кнопка **`[ 📋 Скопировать код ]`**. При нажатии копируется чистый исходный код без лишних символов разметки, а кнопка на 1.5 секунды меняется на **`✓ Скопировано!`**.
- **Копирование всего кода из ответа:** если нейросеть прислала несколько сниппетов, внизу ответа появляется быстрая кнопка **`[ 💻 Скопировать код ]`**, которая объединяет и копирует все фрагменты кода сразу.
- **Копирование текста промпта пользователя:** под каждым вашим сообщением находится аккуратная кнопка **`[ 📋 Скопировать ]`**, позволяющая мгновенно скопировать заданный вопрос для повторного использования или правки.
- **Копирование всего ответа:** кнопка **`[ 📋 Скопировать ответ ]`** в футере сообщения ассистента копирует полный текст ответа с визуальным подтверждением.
- Долгое нажатие на пузырь сообщения по-прежнему работает как резервный способ копирования.

### 4. ⚙️ Умные настройки и пресеты
- Быстрые чипы системного промпта:
  - 💬 **Ассистент** («Ты полезный ассистент…»)
  - 💻 **Программист** («Ты опытный Senior разработчик…»)
  - 🌍 **Переводчик** («Ты профессиональный переводчик…»)
  - 📝 **Редактор** («Исправляй ошибки и стиль…»)
- Пресеты температуры: `0.2` (для кода и точных данных), `0.7` (баланс), `1.2` (креатив).
- Прямая ссылка на генерацию ключа OpenRouter в один клик.

## 📥 Быстрая установка

1. Скачайте APK-файл из репозитория: **[FreeChat.apk](FreeChat.apk)**
2. Установите на любое Android-устройство (требуется Android 5.0+).
3. При запуске укажите ваш API-ключ OpenRouter (подробная инструкция ниже).
4. Выберите нужную модель и начните диалог!

## 🔑 Пошаговая инструкция: Как получить API-ключ OpenRouter

OpenRouter предоставляет единый ключ для доступа к 400+ моделям. **Привязка банковской карты не требуется**, если вы используете бесплатные модели (с меткой `[FREE]`).

### Шаг 1. Перейдите на сайт OpenRouter
1. Откройте в браузере: **[openrouter.ai](https://openrouter.ai)**.
2. В правом верхнем углу нажмите кнопку **«Sign In»** (Войти).
3. Войдите удобным способом:
   - Через **Google** (в один клик)
   - Через **GitHub**
   - Через **Email** (придёт ссылка для быстрого входа)
   - Или через Web3-кошелек (MetaMask)
   > *Никаких зарубежных номеров телефонов или паспортных данных подтверждать не нужно!*

### Шаг 2. Перейдите в раздел ключей API
- Откройте прямую ссылку: **[openrouter.ai/keys](https://openrouter.ai/keys)**
- *Либо вручную:* нажмите на иконку вашего профиля в правом верхнем углу и выберите пункт меню **«Keys»** (Ключи).

### Шаг 3. Создайте новый API-ключ
1. Нажмите синюю кнопку **«Create Key»** (Создать ключ).
2. В появившемся окне:
   - **Key Name:** введите любое понятное название (например, `FreeChat Phone` или `Android`).
   - **Credit limit:** оставьте пустым (без лимита для бесплатных моделей) или укажите желаемый лимит.
3. Нажмите кнопку **«Create»**.

### Шаг 4. Скопируйте и сохраните ключ
1. На экране появится ваш сгенерированный ключ, начинающийся на:
   ```text
   sk-or-v1-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
   ```
2. Нажмите кнопку **«Copy»** рядом с ключом.
   > ⚠️ **Важно:** ключ показывается полностью **только один раз** при создании. Обязательно скопируйте его сразу!

### Шаг 5. Вставьте ключ в FreeChat
1. Откройте приложение **FreeChat** на смартфоне.
2. Если приложение открыто впервые, окно настроек откроется автоматически.
   *(Либо нажмите на кнопку слайдеров настроек в правом верхнем углу).*
3. В поле **«API-КЛЮЧ OPENROUTER»** вставьте скопированный ключ (`sk-or-v1-...`).
4. Нажмите кнопку **«💾 Сохранить и продолжить»**.

🎉 **Готово!** Теперь нажмите на плашку модели внизу экрана, перейдите на вкладку **«[Бесплатные]»** и пользуйтесь топовыми моделями (DeepSeek R1, Gemma, Llama 3.3, Qwen Coder) абсолютно бесплатно и без ограничений!

## 🏗️ Сборка из исходников

Сборка происходит за ~5 секунд через Python без Android Studio:

```powershell
python build_apk.py
```

Скрипт автоматически найдёт локальный Android SDK, скомпилирует исходники, выполнит дексинг через Google D8, выровняет пакет с помощью `zipalign`, подпишет с помощью `apksigner` и сгенерирует готовый `FreeChat.apk`.
