## 🌟 О проекте

**FreeChat** — это автономный, экстремально лёгкий клиент для чата с языковыми моделями через [OpenRouter.ai](https://openrouter.ai). 

В отличие от большинства современных приложений, FreeChat написан на **чистом Android SDK без сторонних библиотек, Jetpack Compose, androidx или тяжелых фреймворков**. Весь размер приложения — **всего ~50 Килобайт**! При этом оно поддерживает полноценный стриминг ответов, прикрепление фото с превью, работу с документами и выбор из десятков бесплатных и платных нейросетей.

---

## ✨ Основные возможности

- 🚀 **Экстремальная легковесность (~50 КБ):** запускается мгновенно на любом устройстве, не расходует память и батарею.
- 🤖 **Любые модели OpenRouter:** бесплатные модели (`:free`) подтягиваются автоматически и сортируются по возможностям.
- 📷 **Зрение и анализ изображений (Vision):**
  - Модели с поддержкой картинок помечены значком `📷` и вынесены в топ списка.
  - Полноценные **интерактивные превью** прикреплённых фото перед отправкой.
  - Отображение фотографий **прямо в пузырях сообщений** чата.
  - **Автоматическая умная оптимизация:** фото с камеры сжимаются до оптимальных 1600 px и 85% качества (вес падает с 15 МБ до ~400 КБ), исключая ошибки переполнения памяти и превышения лимитов API.
- ⚡ **Realtime Streaming (SSE):** вывод ответа нейросети по словам в реальном времени.
- 📄 **Работа с документами и кодом:** прикрепление текстовых файлов, кода, PDF и логов для быстрого анализа.
- 🎨 **Telegram Dark UI:** стильный темный интерфейс в духе Telegram Desktop/Mobile.
- ⚙️ **Гибкая настройка:** системный промпт, температура генерации (0.0 – 2.0) и быстрый доступ к получению API-ключа.
- 🔒 **Конфиденциальность:** ваш API-ключ хранится строго локально в зашифрованном хранилище приложения (`SharedPreferences`) и передаётся только напрямую на официальные сервера OpenRouter.

## 📥 Установка

1. Скачайте свежий релиз: **[FreeChat.apk](FreeChat.apk)**
2. Откройте файл на Android-устройстве и подтвердите установку.
3. При первом запуске введите ваш бесплатный API-ключ OpenRouter (получить можно на [openrouter.ai/keys](https://openrouter.ai/keys)).
4. Готово! Выберите модель из списка внизу и начните общение.

## 🛠️ Стек технологий и архитектура

Проект демонстрирует бескомпромиссный подход к оптимизации размера и производительности:

- **Язык:** Java 8 (Desugared)
- **UI:** Pure Android View Hierarchy (программная верстка без раздутых XML-макетов)
- **Сетевой стек:** `HttpURLConnection` + `Server-Sent Events (SSE)`
- **Парсинг JSON:** Встроенный легковесный `org.json`
- **Графика:** Аппаратный `BitmapFactory` с двухэтапным масштабированием и `ViewOutlineProvider`
- **Зависимости:** **0 external dependencies** (0 байт лишнего кода)

## 🏗️ Сборка из исходников

Для сборки APK не требуется тяжелый Android Studio или Gradle — сборка выполняется за несколько секунд через встроенный Python-скрипт с использованием `Android Build Tools`.

### Требования:
- JDK 17+ или 21
- Android SDK (платформа `android-34`, build-tools `33.0.2` или новее)
- Python 3.8+

### Команда сборки:
```powershell
python build_apk.py
```

Скрипт автоматически:
1. Компилирует Java-файлы через `javac`.
2. Конвертирует байткод в `classes.dex` через Google D8.
3. Упаковывает манифест и ресурсы с помощью `aapt`.
4. Выравнивает архив через `zipalign`.
5. Подписывает финальный пакет с помощью `apksigner`.
6. Генерирует готовый файл **`FreeChat-fixed.apk`**.
